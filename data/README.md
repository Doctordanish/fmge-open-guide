# FMGE Open Guide Data

This directory contains structured datasets used by FMGE Open Guide.

The data is kept separately from the human-readable documentation so that it can later be used for:

- Search
- Tables
- Visualizations
- Websites
- Data analysis
- Year-to-year comparisons

## Current Datasets

### Telangana CRMI 2026–27

File:

`telangana-crmi-2026-27.csv`

This dataset contains the institution-wise FMG CRMI allocations published for Telangana for the 2026–27 academic year.

The institution numbering follows the NMC Annexure-II listing.

## Source

Primary source:

National Medical Commission (NMC)

Document:

**Allocation of Compulsory Rotating Medical Internship (CRMI) Slots for Foreign Medical Graduates (FMGs)**

Date:

10 March 2026

The official NMC document should be treated as the source of record.

## Verification

Dataset verification date:

23 September 2026

The data should be rechecked whenever NMC publishes a revised allocation, correction, or subsequent academic-year allocation.

## Important Distinction

CRMI allocation data is not the same as MBBS seat-capacity data.

For example, an institution may have:

- A particular number of approved MBBS seats
- A different number of FMG CRMI slots

These figures should not be substituted for one another.

## Aggregate Validation

The NMC Annexure-I aggregate for Telangana is:

**4,871 CRMI slots**

The institution-level Telangana entries currently reproduced in this repository sum to:

**4,868 CRMI slots**

This produces a difference of:

**3 slots**

The discrepancy is intentionally documented rather than silently corrected.

Possible explanations include:

- A transcription difference
- A source-document discrepancy
- A later correction
- A difference between the aggregate and institution-level listing

The repository should not assume the explanation without evidence.

Until the discrepancy is resolved, the NMC-published aggregate and the institution-level dataset should both be preserved and clearly labelled.

## Data Integrity Rules

When updating this dataset:

1. Do not silently change historical values.
2. Record the source and verification date.
3. Preserve institution numbering where practical.
4. Distinguish corrections from new academic-year datasets.
5. Recalculate the aggregate after changes.
6. Investigate discrepancies rather than forcing totals to match.
7. Do not interpret a published allocation as an individual's guaranteed internship placement.
