# State-by-State FMG Guide

**Last verified:** 23 September 2026

This section documents state-specific procedures relevant to Foreign Medical Graduates (FMGs), including internship, CRMI allocation, medical registration and related administrative processes.

> **Important:** State procedures can change independently of national regulations. Always verify current instructions with the relevant State Medical Council, Directorate of Medical Education and institution.

---

# 1. Why State-Specific Information Matters

The national regulatory framework is established primarily through the National Medical Commission (NMC) and applicable regulations.

However, an FMG may also need to interact with:

- State Medical Council
- Directorate of Medical Education
- State Government health / medical education department
- Medical colleges
- Teaching hospitals
- Other designated authorities

As a result, the practical process can differ between states.

A requirement reported by an FMG in one state should not automatically be assumed to apply nationwide.

---

# 2. What Each State Guide Should Contain

Where sufficient information has been verified, each state page should document:

### Medical Council

- Official name
- Official website
- Registration process
- Contact information
- Relevant forms

### CRMI / Internship

- FMG eligibility
- CRMI allocation
- State-level allotment procedure
- Application process
- Participating institutions
- Internship documentation

### Fees

- Official application fees
- Registration fees
- Institutional fees where officially documented

### Stipend

- Applicable stipend rules
- Government / institutional orders
- Implementation information

### Registration

- Provisional registration
- Internship completion
- Permanent registration
- Required documents
- Verification process

### Practical information

- Common administrative problems
- Dated FMG experiences
- Institutional differences
- Verified community reports

Community information should always be clearly distinguished from official requirements.

---

# 3. Source Hierarchy

State-specific information should be verified using the following hierarchy:

1. **State Government / official notification**
2. **State Medical Council**
3. **Directorate of Medical Education**
4. **NMC**
5. **Medical college / hospital official communication**
6. **Dated community experience**
7. **Social-media discussion**

Where sources conflict, the conflict should be documented rather than silently resolved.

---

# 7. How Community Reports Should Be Used

Community reports can be extremely useful for identifying practical issues that are not obvious from official documents.

For example, an FMG may report:

> "The college asked for an additional document that was not mentioned on the website."

That report can be useful evidence of a practical issue.

However, it should **not** automatically be converted into:

> "The state requires this document."

The guide should distinguish:

**Official requirement**

from

**Institutional practice**

from

**Individual experience**

from

**Interpretation / advice**

---

# 8. Reporting State-Specific Problems

If you are contributing information about a state, provide as much of the following as possible:

- State
- Authority / institution
- Date
- Type of process
- What happened
- Official source, if available
- Supporting document
- Whether the information was independently verified

Avoid publishing personal information unnecessarily.

---

# 9. Keeping State Guides Current

State procedures can become outdated quickly.

Every state page should therefore record:

**Last verified:** DD Month YYYY

and maintain a verification history.

When a new government order, NMC notice or State Medical Council instruction changes the process, the relevant page should be updated.

Older information should not simply be deleted when it remains useful for historical context; it should be clearly marked as outdated where appropriate.

---

# 10. Goal of This Section

The goal is not to create another unofficial list of "best" states or colleges.

The goal is to create a **source-backed map of how the FMG process actually works in each state**.

This allows an FMG to answer practical questions such as:

- Where do I apply?
- Which authority handles my registration?
- How are CRMI seats allocated?
- Which institutions have documented FMG capacity?
- What documents are required?
- What fees are officially published?
- What stipend rules apply?
- What problems have other FMGs reported?
- Which information is official and which is only community experience?
