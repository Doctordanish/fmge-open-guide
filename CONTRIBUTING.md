# Contributing to FMGE Open Guide

Thank you for helping improve FMGE Open Guide.

This project is intended to be a reliable, source-driven knowledge base for Foreign Medical Graduates navigating medical licensure, internship, registration, and related pathways in India.

## What You Can Contribute

Useful contributions include:

- Official NMC notices
- NBEMS notices and information bulletins
- State Medical Council requirements
- Directorate of Medical Education notices
- Official college/institution requirements
- State-specific registration procedures
- CRMI/internship information
- Corrections to outdated information
- Clarification of confusing procedures
- Document checklists
- FMG experiences that help identify issues or questions that should be investigated

## Source Priority

When adding factual information, use the strongest available source.

### Preferred

1. NMC
2. NBEMS
3. State Medical Councils
4. State government / Directorate of Medical Education
5. Official institutional websites or notices

### Secondary

Community sources such as:

- Reddit
- Telegram
- WhatsApp
- Forums
- Personal experiences
- Social media

Community information can be useful, particularly for identifying practical problems, but it should not be presented as an official rule unless supported by an authoritative source.

## Community Experiences

Personal experiences are valuable, but they must be clearly distinguished from official requirements.

For example:

> Community report: An FMG reported that a particular institution requested document X during its application process.

Do not write:

> Document X is required by all FMGs.

unless an authoritative source supports that statement.

## Verification

When possible, include:

- Source
- Date of the source
- Date the information was checked
- Relevant notice/document title
- Link to the original source

For information that can change frequently, prefer the most recent official source available.

## Corrections

If you find an error:

1. Explain what appears to be incorrect.
2. Provide the source supporting the correction.
3. Include the relevant date.
4. Explain whether the change affects the current procedure.

Do not silently replace important information when the change needs explanation.

## Conflicting Information

If two sources appear to conflict:

- Preserve both sources initially.
- Identify the dates of the sources.
- Prefer the newer authoritative source where appropriate.
- Explain the conflict rather than hiding it.
- Do not assume that a college-level requirement overrides an NMC or government regulation.

## CRMI and Seat Data

Do not assume that:

- An MBBS seat is a CRMI seat.
- A CRMI allocation guarantees an individual FMG a seat.
- A college's historical practice is its current official requirement.
- A published seat number represents current availability.

Different datasets should remain clearly separated.

## No Unverified Claims

Avoid statements such as:

- "This college definitely accepts FMGs."
- "This is the cheapest college."
- "This college always gives stipend."
- "You can definitely get a seat here."
- "NMC has approved this university."

unless the statement can be supported by appropriate evidence.

## Pull Requests

If you are comfortable with GitHub:

1. Fork the repository.
2. Create a branch for your change.
3. Make the change.
4. Explain what you changed.
5. Include sources for factual claims.
6. Submit a pull request.

Small corrections are welcome.

## Reporting Information

If you do not know how to make a pull request, you can open a GitHub issue describing:

- The problem
- The state/institution concerned
- What you believe should be changed
- Supporting evidence
- Source links
- Date of the information

## Principle

The goal is not to collect the largest amount of information.

The goal is to make the information **useful, traceable, current, and honest about its level of certainty**.
